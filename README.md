This project aims to create a secure, transparent, and fraud-resistant voting system using blockchain technology. Unlike traditional voting systems, where trust relies on central authorities, this system leverages smart contracts to ensure fairness and immutability.

 Features
 Decentralized – The voting process is recorded on the blockchain, making it tamper-proof.
 Secure – Users can vote only once, preventing fraud.
 Transparent – Voting results are publicly verifiable.
 Anonymous – Voter identities are not directly exposed (can be anonymized using hashing).

Technologies Used
Solidity – Smart contract development.
React.js – Frontend for the voting system.
Web3.js / Ethers.js – Interaction with the blockchain.
